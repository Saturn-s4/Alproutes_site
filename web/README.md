# Web

Next.js 16 (App Router), TypeScript, MapLibre GL JS. Клиент API `/api/v1` backend на Kotlin, своей логики и БД нет.

## Запуск

```bash
docker compose -f infra/docker-compose.yml up -d db seaweedfs s3-init
cd backend && ./gradlew bootRun --args='--spring.profiles.active=dev'
cd web && npm install && npm run dev
```

Открыть `http://localhost:3000`. Вход — `/login` (dev-вход backend, без OAuth). Тестовые данные — `infra/dev-seed`.

| `/login` | dev-вход | клиент |

## Как устроено

- **Типы API** генерируются из `/shared/openapi.yaml` (`npm run gen:api`, запускается автоматически перед `dev` и `build`). Файл `src/lib/api/schema.d.ts` не коммитится. Запросы — через `openapi-fetch`, типизированный по этим типам.
- **Прокси.** Браузер ходит на `/api/v1/*` того же origin, Next проксирует на `API_URL` (`next.config.ts`). Серверные компоненты обращаются к `API_URL` напрямую.
- **SSR.** Каталог, районы и маршруты рендерятся на сервере ради индексации; формы, модерация и карта — клиентские. Фильтры каталога — обычные ссылки с параметрами: работают без JS.
- **Язык и тема** хранятся в cookie (`lang`, `theme`), чтобы сервер сразу рендерил нужный вариант. Тема: системная / тёмная / светлая.
- **Сессия** — пара токенов в `localStorage`, обновление access-токена в один поток (требование контракта).
- **Карта** — растровые тайлы OpenTopoMap. В тёмной теме они инвертируются paint-свойствами raster-слоя, а не CSS-фильтром, поэтому линии и точки сохраняют свои цвета. Воркер MapLibre копируется в `public/maplibre` (`npm run prepare:assets`): бандлер не умеет разрешать его путь сам.
- **Редактор геометрии** (`components/edit/GeometryEditor.tsx`) — свой, без библиотеки: точки и линии типов из контракта, перетаскивание, вставка вершины через середину отрезка, удаление правым кликом, ввод координат вручную (`lib/coords.ts`: десятичные градусы, градусы-минуты, DMS, буквы полушарий), линия из GPX/KML-трека.
- **Загрузка файлов** (`lib/upload.ts`) — по pre-signed URL прямо в S3, мимо backend; затем создаётся сущность с `uploadId`. Нужен CORS на хранилище для origin веба (SeaweedFS локально разрешает любой — в продакшене сузить).
- **Треки.** Статистика и профиль высот — только с сервера (сглаженные). В браузере GPX/KML читается (`lib/gpx.ts`) лишь чтобы взять линию в маршрут до его создания; файл после создания маршрута загружается к нему как трек.
- **Фото.** Фото описания (подписи из ревизии) и галерея участников (`inDescription=false`), полноэкранный просмотр — `Lightbox`. Картинки берутся напрямую из публичного бакета.
- **PDF** открываются встроенным просмотрщиком браузера в `iframe`: `/api/v1/documents/{id}/download` отвечает редиректом на временную ссылку. pdf.js понадобится для своего интерфейса просмотра (мобильные браузеры PDF в iframe показывают плохо).
- **Данные не додумываются.** Пустое поле формы уходит как `null` («нет данных»), категория без выбранного значения не отправляется, категории всегда показываются с системой.
- **Стили** перенесены из `web-prototype/src/styles` (варианты A и B).
