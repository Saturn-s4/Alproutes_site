# web-prototype

Кликабельный прототип интерфейса Alproutes на демо-данных. Это **референс внешнего вида** (вариант A «Карта в центре»), а не основа продукта: настоящий веб-клиент — Next.js в `/web`, данные — из backend по контракту `/shared/openapi.yaml`. Правила переноса из прототипа — в разделе 5 корневого `CLAUDE.md`.

React 19 + TypeScript + Vite, карта — Leaflet с тайлами OpenTopoMap / Esri (в продукте — MapLibre).

## Расхождения с продуктом

Прототип рисовался раньше контракта, поэтому показывает то, чего в продукте нет или что устроено иначе:

| В прототипе | В продукте (контракт) |
|---|---|
| Вход по email и паролю, восстановление пароля, VK ID | Вход только через Google и Apple |
| «Мои маршруты» с видимостью публичный / по ссылке / приватный | Общий каталог: правки через ревизии и модерацию |
| Отзывы, избранное | Комментарии и записи о восхождениях; избранного нет |
| «Время» и «участки» маршрута | Таких полей нет |
| Сезон: весна / лето / осень / зима | Месяцы 1–12 |
| Одна категория по российской шкале | Несколько систем, не больше одной категории на систему |
| Координаты `[lat, lon]`, профиль высот по сырому GPX | GeoJSON `[lon, lat]`, сглаженный профиль с сервера |
| Нет дисклеймера, PDF показываются всегда | Дисклеймер на каждом маршруте, PDF — только с выясненными правами |

## Страницы

| Адрес | Экран |
|---|---|
| `#/` | Главная, направление A: список маршрутов в области карты, живая карта, панель выбранного маршрута |
| `#/catalog` | Каталог с фильтрами по категории, району и материалам |
| `#/route/:id` | Страница маршрута: галерея, описание, участки, треки, архив PDF, отзывы, карта и профиль высот |
| `#/upload` | Добавление маршрута: разбор GPX/KML, расчёт длины, набора и высот, фото, описание, PDF, готовность |
| `#/login` | Вход и регистрация |
| `#/profile` | Профиль: мои маршруты, треки, избранное, отзывы и настройки интерфейса |

## Что работает в прототипе

- Тёмная и светлая темы, а также режим «Как в системе». Все цвета — токены из дизайна (`src/styles/tokens.css`).
- Интерфейс на русском и английском (`src/i18n.ts`), единицы — метры или футы.
- Сетка 1600 → 4K по таблице адаптации: базовый шрифт 14/15/17/20 px, список 360/400/480/560 px, панель 420/460/560/640 px, на 4K появляется дополнительная колонка с фото и отзывами. Ниже 1600 px вёрстка перестраивается до мобильной.
- Карта: слои «Топо», «Спутник» и «Рельеф», зум, показ или скрытие чужих треков, список фильтруется по видимой области, поиск в шапке.
- Скачивание GPX, избранное, отзывы, публикация своих маршрутов с настоящим разбором трека.

## Данные

Прототип к backend не подключается. Маршруты в `src/data/routes.ts` — демо: координаты и треки приблизительные, тексты описаний и PDF — плейсхолдеры в квадратных скобках. Аккаунт, избранное, отзывы и добавленные маршруты хранятся в `localStorage` браузера. Вход через Google и VK ID, восстановление пароля и скачивание архивов показывают сообщение, что функция появится после подключения сервера.

## Запуск

```bash
npm install
npm run dev
```

Сборка — `npm run build`, результат в `dist/`.

## Деплой

`.github/workflows/deploy.yml` собирает проект и публикует его на GitHub Pages при каждом пуше в `main`. Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**. Роутинг на хэшах (`#/route/...`), поэтому прямые ссылки работают без настройки сервера.

## Структура

```
src/
  components/   шапка, карта (Leaflet), профиль высот, иконки
  pages/        страницы
  data/         демо-маршруты и типы
  lib/geo.ts    расстояния, статистика трека, разбор GPX/KML, экспорт GPX
  styles/       токены тем и стили
  i18n.ts       словари RU/EN
  store.tsx     настройки, пользователь, избранное, отзывы, свои маршруты
design/         исходные макеты с холста (*.dc.html) и их просмотрщик
```
