# Alproutes_site

Веб-интерфейс Alproutes — каталог альпинистских маршрутов: карта, GPX-треки, архивные PDF-описания и отзывы.

React 19 + TypeScript + Vite, карта — Leaflet с тайлами OpenTopoMap / Esri.

## Страницы

| Адрес | Экран |
|---|---|
| `#/` | Главная, направление A: список маршрутов в области карты, живая карта, панель выбранного маршрута |
| `#/catalog` | Каталог с фильтрами по категории, району и материалам |
| `#/route/:id` | Страница маршрута: галерея, описание, участки, треки, архив PDF, отзывы, карта и профиль высот |
| `#/upload` | Добавление маршрута: разбор GPX/KML, расчёт длины, набора и высот, фото, описание, PDF, готовность |
| `#/login` | Вход и регистрация |
| `#/profile` | Профиль: мои маршруты, треки, избранное, отзывы и настройки интерфейса |

## Что работает

- Тёмная и светлая темы, а также режим «Как в системе». Все цвета — токены из дизайна (`src/styles/tokens.css`).
- Интерфейс на русском и английском (`src/i18n.ts`), единицы — метры или футы.
- Сетка 1600 → 4K по таблице адаптации: базовый шрифт 14/15/17/20 px, список 360/400/480/560 px, панель 420/460/560/640 px, на 4K появляется дополнительная колонка с фото и отзывами. Ниже 1600 px вёрстка перестраивается до мобильной.
- Карта: слои «Топо», «Спутник» и «Рельеф», зум, показ или скрытие чужих треков, список фильтруется по видимой области, поиск в шапке.
- Скачивание GPX, избранное, отзывы, публикация своих маршрутов с настоящим разбором трека.

## Данные

Бэкенда пока нет. Маршруты в `src/data/routes.ts` — демо: координаты и треки приблизительные, тексты описаний и PDF — плейсхолдеры в квадратных скобках. Аккаунт, избранное, отзывы и добавленные маршруты хранятся в `localStorage` браузера. Вход через Google и VK ID, восстановление пароля и скачивание архивов показывают сообщение, что функция появится после подключения сервера.

## Запуск

```bash
npm install
npm run dev
```

Сборка — `npm run build`, результат в `dist/`.

## Деплой

`.github/workflows/deploy.yml` собирает проект и публикует его на GitHub Pages при каждом пуше в `main`. Один раз нужно включить: Settings → Pages → Source: **GitHub Actions**. Роутинг на хэшах (`#/route/...`), поэтому прямые ссылки работают без настройки сервера.

## Структура

```
src/
  components/   шапка, карта (Leaflet), профиль высот, иконки
  pages/        страницы
  data/         демо-маршруты и типы
  lib/geo.ts    расстояния, статистика трека, разбор GPX/KML, экспорт GPX
  styles/       токены тем и стили
  i18n.ts       словари RU/EN
  store.tsx     настройки, пользователь, избранное, отзывы, свои маршруты
design/         исходные макеты с холста (*.dc.html) и их просмотрщик
```
