# Alproutes_site

Веб-интерфейс Alproutes — каталог альпинистских маршрутов с картой, GPX-треками, архивными PDF и отзывами.

Здесь — все экраны из дизайна, собранные в статический сайт без сборки и зависимостей.

## Как открыть

Светлые варианты подгружают базовые экраны через `fetch`, поэтому сайт нужно открывать через HTTP-сервер, а не как `file://`:

```bash
py -m http.server 8000
```

Затем откройте http://localhost:8000.

Для публикации на GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Как это устроено

- Каждый `*.dc.html` — самостоятельный экран: разметка внутри `<x-dc>` с подстановками `{{…}}`, `<sc-for>`, `<sc-if>`, `<dc-import>` и логика в `<script type="text/x-dc">` (`class Component extends DCLogic`).
- `support.js` — небольшой рантайм, который рендерит этот формат в браузере: подставляет значения, разворачивает циклы и условия, вешает обработчики `onClick`, подгружает импортированные экраны.
- Тема и язык берутся из `?theme=light&lang=en` в адресе или из последнего выбора (хранится в `localStorage`).
- `design/canvas.json` — раскладка исходного холста дизайна (позиции и названия артбордов).
