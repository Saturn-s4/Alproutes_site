# Тестовые данные для локальной разработки

Только для dev-базы. Всё содержимое **сгенерировано и помечено «ТЕСТ»**: это не реальные маршруты, категории, координаты и фото. Не загружать в общую или боевую базу.

```bash
java infra/dev-seed/GenerateSamples.java infra/dev-seed/samples   # картинки и PDF (нужен JDK 21)
node infra/dev-seed/seed.mjs                                      # нужен запущенный backend в профиле dev
```

`seed.mjs` работает через публичный API так же, как клиенты: dev-вход, pre-signed загрузка, создание сущностей. Повторный запуск ничего не дублирует.

Что создаётся:

- районы `demo-region` → `demo-summit`;
- маршруты `demo-route-1` (геометрия, две категории, 3 фото описания, 4 фото участников, трек, 2 PDF), `demo-route-2` (без категории), `demo-route-3` (без геометрии);
- пользователи `mod@local` (модератор), `anna@local`, `boris@local`;
- PDF: один с правовым статусом `own_work` и опубликован, второй оставлен в очереди модерации.

Слаги с префиксом `demo-`, чтобы не пересекаться с фикстурами `infra/db/tests`. Папка `samples/` генерируется и не коммитится.
